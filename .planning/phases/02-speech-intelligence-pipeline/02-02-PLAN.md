  <name>Task 1: Install Zod and Google Gen AI SDK, define CanvasActionSchema</name>
  <files>package.json, src/types/actions.ts</files>
  <read_first>.planning/research/ARCHITECTURE.md</read_first>
  <action>
    Install dependencies:
    - `npm install zod @google/genai`
    Create src/types/actions.ts:
    - Import `z` from "zod"
    - Define `CanvasActionSchema` as a discriminated union on `"action"`:
      1. `create_mindmap`:
         - action: z.literal("create_mindmap")
         - rootTitle: z.string().min(1).max(80)
         - branches: z.array(z.string().min(1).max(100)).min(1).max(8)
         - suggestedLayout: z.enum(["radial", "horizontal"]).default("horizontal")
      2. `create_node`:
         - action: z.literal("create_node")
         - label: z.string().min(1)
         - nodeType: z.enum(["note", "card", "quiz_block"])
         - relativeToNodeId: z.string().optional()
         - placement: z.enum(["right", "bottom", "left", "top"]).default("right")
      3. `connect_nodes`:
         - action: z.literal("connect_nodes")
         - sourceNodeId: z.string()
         - targetNodeId: z.string()
         - label: z.string().optional()
      4. `set_countdown_timer`:
         - action: z.literal("set_countdown_timer")
         - durationSeconds: z.number().int().positive().max(3600)
         - title: z.string().optional()
    - Export `CanvasAction` inferred type: `export type CanvasAction = z.infer<typeof CanvasActionSchema>`
    - Export LLMRequest and LLMResponse types:
      - `LLMRequest`: `{ transcript: string; spatialContext: CanvasSpatialContext }`
      - `LLMResponse`: `{ success: boolean; action?: CanvasAction; error?: string; raw?: unknown }`
  </action>
  <verify>npm run build</verify>
  <acceptance_criteria>
    - package.json includes "zod" in dependencies
    - src/types/actions.ts exports CanvasActionSchema and CanvasAction type
    - CanvasActionSchema is a strict Zod discriminated union on "action"
  </acceptance_criteria>
  <done>Zod schema boundary is created for strict deterministic tool validation</done>

    - Next.js App Router POST handler

    - Calls `generateCloudAction(transcript, spatialContext)`
    - Validates returned output using `CanvasActionSchema.safeParse(json)`
    - If validation fails: returns 400 with `{ success: false, error: validationError.message }`
    - If valid: returns 200 with `{ success: true, action: validatedAction }`
