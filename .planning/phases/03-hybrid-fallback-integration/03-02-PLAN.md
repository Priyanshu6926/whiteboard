<objective>
Implement the chunked WebM audio recording pipeline using the MediaRecorder API to provide a robust audio capture fallback when the streaming Web Speech API is unavailable, degraded, or unsupported.

Purpose: Guarantee voice accessibility across all browser engines (including browsers without Web Speech API support) and in high-noise classroom environments by slicing audio into 3-second WebM buffers.
Output: `useAudioChunkRecorder` hook, `/api/audio/transcribe` route, `AudioChunkModal` interface, and end-to-end fallback transcription dispatch.
</objective>
