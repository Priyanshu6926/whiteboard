  <action>
    Create src/server/syncServer.ts:
    - Node.js standalone HTTP + Socket.IO server running on port 4001 (or process.env.SYNC_PORT || 4001)
    - CORS configured for localhost:3000 and dynamic client origins
    - In-memory room store tracking:
      - `rooms: Map<string, { teacherSocketId?: string; viewerSocketIds: Set<string>; sequenceId: number; history: CanvasDeltaPayload[] }>`
    - Event handlers:
      - `join-room`: adds socket to room, notifies room of updated viewer count, sends latest sequenceId
      - `canvas-delta`: validates sequenceId, appends to room history, broadcasts delta to all other sockets in room with sub-120ms latency
      - `request-snapshot`: allows new joiners to fetch recent delta history or snapshot
      - `disconnect`: cleans up sockets and updates viewer count
    - Add npm script to package.json: `"sync-server": "node --import tsx/esm src/server/syncServer.ts"` or `tsx src/server/syncServer.ts`
    Create src/services/persistence/indexedDbStore.ts:
    - Uses `idb` library to open database `voxcanvas_db` (version 1) with object store `canvas_snapshots`
    - Functions:
      - `saveCanvasSnapshot(roomId: string, records: Record<string, unknown>[]): Promise<void>`
      - `loadCanvasSnapshot(roomId: string): Promise<Record<string, unknown>[] | null>`
      - `clearCanvasSnapshot(roomId: string): Promise<void>`
    - Automatic 3-second timer utility `startPeriodicPersistence(editor: Editor, roomId: string, intervalMs = 3000): () => void` (SYNC-03)
  </action>
