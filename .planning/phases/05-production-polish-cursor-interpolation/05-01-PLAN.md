      ```typescript
      }

        p0: Point2D;
        p1: Point2D;
        p2: Point2D;
        p3: Point2D;
      }
      ```
    - Implement cubic Bezier evaluation function:
      `calculateCubicBezier(p0, p1, p2, p3, t): Point2D`
      Formula: $B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3$ for $t \in [0, 1]$
    - Implement control point generator:
      `generateControlPoints(start: Point2D, end: Point2D, curvature = 0.25): BezierCurve`
      Calculates ergonomic arc control points $P_1$ and $P_2$ displaced perpendicularly to the chord vector $(P_3 - P_0)$, producing natural swooping curves rather than robotic straight lines.
    - Implement easing functions:
      `easeOutCubic(t: number): number = 1 - Math.pow(1 - t, 3)`
      `easeInOutQuad(t: number): number`
    - Implement tangent / angle calculation for rotating the cursor icon towards its movement direction:
      `calculateTangentAngle(p0, p1, p2, p3, t): number`
  </action>
